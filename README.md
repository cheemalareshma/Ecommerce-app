# Ecommerce-app
**MERN Stack E-Commerce Platform**

Developed a full-stack E-Commerce web application using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The platform includes a customer-facing frontend, a secure backend API, and a dedicated admin panel for managing products, orders, and users.

**Key Features:**

* User authentication and authorization using JWT.
* Product browsing, search, filtering, and category management.
* Shopping cart and checkout functionality.
* Order placement and order tracking system.
* Admin dashboard for managing products, inventory, users, and orders.
* RESTful APIs built with Express.js and Node.js.
* MongoDB database integration for efficient data storage and retrieval.
* Responsive and user-friendly interface built with React.js.
* Secure data handling and role-based access control.
* Full CRUD operations for products, categories, and orders.

**Tech Stack:** MongoDB, Express.js, React.js, Node.js, JavaScript, REST APIs, JWT Authentication, HTML, CSS, and Git.
